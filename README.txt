MY GIRL — Happy Girlfriend Day

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html di browser.
3. Klik "Buka untuk kamu, sayang" agar musik MyGirl.mp3 diputar.

Untuk GitHub Pages:
- Upload index.html dan folder assets ke repository.
- Settings > Pages > Deploy from branch > main / root.
- Gunakan link HTTPS GitHub Pages untuk dikirim melalui WhatsApp.


Versi CONFESS: bagian akhir memiliki pilihan "Iya, aku mau" dan "Maaf, tidak".
